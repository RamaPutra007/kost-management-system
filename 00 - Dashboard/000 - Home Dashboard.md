# Kost Management System

Welcome to the Kost Management System documentation. This map serves as the central hub connecting all the project specifications, creating a unified Graph View for the project.

## Project Overview
Kost Management System adalah aplikasi manajemen rumah kost yang dirancang untuk membantu pemilik kost (Owner) dan Admin dalam mengelola operasional sehari-hari, termasuk manajemen kamar, penghuni, tagihan, dan pengeluaran.

## Core Modules
Manajemen informasi properti kost, manajemen data kamar, manajemen penghuni, manajemen kontrak sewa, pembuatan tagihan, verifikasi pembayaran, pencatatan pengeluaran, dan pelaporan keuangan.

## User Roles
- Owner: Akses penuh dan monitoring.
- Admin: Mengelola operasional harian.
- Penghuni: Akses terbatas (cek tagihan & riwayat).
